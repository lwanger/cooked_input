
Test the readme text with (make sure readme_renderer is pip installed):

python setup.py check -r -s


to check the wheel and metadata use:

unzip -c dist/cooked_input-0.3.5-py2.py3-none-any.whl  cooked_input-0.3.5.dist-info/WHEEL

unzip -c dist/cooked_input-0.3.5-py2.py3-none-any.whl  cooked_input-0.3.5.dist-info/METADATA

uploading to pypi:

test first with:

twine upload dist/* -r testpypi

then do on the production server:

twine upload dist/*
